# ToolsVianko — AI Quick Context

Resumen de alta densidad para optimización de tokens y contexto.

## 📌 ADN del Proyecto
- **Propósito**: Suite de herramientas internas de alta performance (Banner Studio, Stress Testing).
- **Core**: React + Vite 6 + Framer Motion.
- **Filosofía**: Rendimiento de 60 FPS y UI premium.

## 📂 Estructura
- `app/SharedTool`: Átomos y lógica compartida.
- `app/BannerStudioTool`: Edición de capas y exportación.
- `app/K6StressTool`: Auditoría y reportes de resiliencia.

## 📜 Reglas Clave
1. **Rendimiento**: Evitar `blur` excesivo y filtros GPU en bucles.
2. **Arquitectura**: Separación de lógica/estilos (Patrón de ViankoSystems).
3. **Lazy Loading**: Todo módulo nuevo debe integrarse en el `HubModule` mediante carga diferida.
